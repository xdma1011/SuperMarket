# قائمة التحقق قبل الافتتاح

> مبنية على قراراتك: الأجهزة الوحيدة مسدس الباركود (بلا طابعة ولا درج مربوط)، الضريبة مش مهمة هلق، والفريط رقم ثابت معروف عندك.
> ضع علامة ✅ لما تخلص البند. **الأسبوع التجريبي (القسم 4) هو التأمين الحقيقي** — ما تتخطاه.

---

## 1) قبل الأسبوع التجريبي (إعداد لمرة وحدة)

### قاعدة البيانات والتشغيل
- [ ] خذ نسخة `.bak` من قاعدتك الحقيقية **قبل** أي شي.
- [ ] `git pull` على `main`، وبعدها: `dotnet ef database update --project SupermarketSystem.Infrastructure --startup-project SupermarketSystem.API`
- [ ] شغّل الـAPI وتأكد إن سجل `logs\api-<التاريخ>.log` ما فيه رسالة "Migration ما انطبقت".
- [ ] مفتاح JWT: اضبط متغيّر البيئة `Jwt__SigningKey` بقيمة جديدة (القديمة كانت مكشوفة بمستودع عام)، وتأكد إن المستودع private.
- [ ] ضبط `ASPNETCORE_ENVIRONMENT` وطريقة التشغيل: لو شباك bat، **ما تسكّره بالغلط**؛ الأفضل Windows Service أو مهمة تشغيل تلقائي.
- [ ] **UPS** لجهاز الـAPI (وقاعدة SQL Server).
- [ ] Smart App Control: إذا مفعّل ممكن يمنع تشغيل ملفات جديدة بعد تحديث. جرّب تشغيل كل شي بعد آخر `git pull` قبل يوم الافتتاح.

### النسخ الاحتياطي (أهم نقطة)
- [ ] من الإعدادات الحسّاسة: حدد `Backup.StorageDirectory` بمجلد **يكتب عليه حساب تشغيل الـAPI** (مش مجلد SQL Server الافتراضي المحمي).
- [ ] حدد `Backup.SecondaryDirectory` على **جهاز أو فلاشة أو Drive تانية** (مش نفس الهارد).
- [ ] اعمل نسخة يدوية من صفحة النسخ الاحتياطي وتأكد: حجمها أكبر من صفر، وإنها نزلت بالمجلدين.
- [ ] **جرّب الترجيع فعلًا:** `RESTORE DATABASE` باسم جديد فيه كلمة `test` أو `kept` (مثل `sprmrkt_kept_<التاريخ>`) وافتح لوحة الإدارة عليها. نسخة ما انجرّب ترجيعها = ما بتعتبر نسخة.
- [ ] تأكد إن تنبيه "فشلت النسخة الاحتياطية" بيوصل (تلغرام).

### الإعدادات
- [ ] توقيت المحل (الإعدادات ← التوقيت): المنطقة `Asia/Amman` أو الفرق اليدوي لو ثبّتوا الساعة.
- [ ] بوت تلغرام: التوكن مضبوط وجرّبت تنبيه حقيقي يوصلك. (بلا تلغرام: التنبيهات بتضل بالنظام بس ما بتوصلك.)
- [ ] اسم المحل (يظهر بالدخول).
- [ ] حدود الخصم اليدوي، حد قيمة الإرجاع المرتفع، حد عجز الصندوق للتنبيه (0 = أي فرق ينبّه).
- [ ] `Cashier.MinimumVersion`: اتركه فاضي لحد ما تحتاجه.

### المستخدمون والأدوار
- [ ] حساب لكل كاشير (مش حساب مشترك)، بدور "كاشير" وبالفرع الصحيح.
- [ ] حسابك Master Admin، وحساب مساعد أدمن لو لزم. باسوردات قوية.
- [ ] جرّب إن الكاشير **ما بيشوف** التقارير ولا المالية ولا التنبيهات (لازم 403/مخفية).
- [ ] الشركاء (إن وجدوا): أضفهم بصفحة الشركاء مع رأس المال الأول، والمضارب بنسبته.

## 2) البيانات (قبل أول بيعة)

- [ ] الفروع، وحدات القياس (جاهزة)، طرق الدفع (نقد، فيزا، كليك).
- [ ] الموردون.
- [ ] **الأصناف:** اسم، تصنيف، وحدة أساسية، **باركود** لكل صنف (وباركود الكرتونة لو بتبيع كرتونة)، وحدات التحويل.
- [ ] **كل صنف يُربط بالفرع + سعر البيع** من "الفروع والأسعار" (وإلا الكاشير ما بيشوفه). افتح الكاشير وتأكد إن الكتالوج مو فاضي.
- [ ] **بضاعة الافتتاح:** صفحة المشتريات ← "رصيد افتتاحي" (بتكلفة الشراء الفعلية، بلا مورد). **لازم قبل أول بيعة** وإلا الأصناف بتنباع بلا تكلفة والأرباح وأنصبة الشركاء بتتشوه.
- [ ] راجع المخزون الحالي (صفحة "المخزون الحالي") وقارنه بالجرد الفعلي لعينة من 20 صنف.
- [ ] جرّب بيع كل نوع: صنف عادي، كرتونة، صنف عليه عرض، صنف بدفعات/صلاحية (لو عندك).

---

## 3) فحص الكاشير والباركود

- [ ] الكاشير يتثبّت ويشتغل على جهاز البيع، والإعداد `ApiBaseUrl` على عنوان الـAPI الصحيح (جهاز الكاشير يوصل لجهاز الـAPI على شبكة المحل).
- [ ] **مسدس الباركود:** مضبوط على إرسال **Enter** بالنهاية. لغة الكيبورد **إنجليزي** وقت المسح (العربي بيخربط).
- [ ] امسح **50 صنف حقيقي**: كلها لازم تنضاف للسلة بسعرها الصح. سجّل أي صنف ما انقرأ أو مش موجود وعالجه.
- [ ] الطباعة: اضبط `PrinterConnectionType=None` (بلا طابعة) عشان ما تطلع رسالة مزعجة.
- [ ] جرّب: بيع نقد، بيع فيزا، بيع بالدين (برقم الزبون)، إرجاع، إلغاء فاتورة، تعليق فاتورة وإرجاعها، فتح الصندوق.
- [ ] **أوفلاين:** افصل الشبكة، اعمل بيعتين، رجّعها: لازم توصل مرة وحدة بوقتها الصح (شوف الفاتورة بالويب).
- [ ] تقفيل الصندوق: **اكتب النقد المعدود ناقص الفريط** (الفريط رقم ثابت عندك).
- [ ] اتفق مع الكاشيرية: ما حدا يسكّر الكاشير بنص وردية، ولو ظهرت رسالة "بيعات معلّقة" عند التقفيل يبلغوك.

## 4) الأسبوع التجريبي (النظام + دفتر ورقي بالتوازي)

**كل يوم، بآخر اليوم، قارن:**
- [ ] **النقد:** المتوقع بالتقفيل = العدّ الفعلي ناقص الفريط. أي فرق، اكتبه واسأل الكاشير (وسجّل التفسير بصفحة "تقفيل الصندوق ← تفسير الفرق").
- [ ] **مجموع المبيعات:** تقرير ملخّص المبيعات = مجموع الدفتر الورقي.
- [ ] **الفيزا:** المبلغ بالنظام = إغلاق جهاز الفيزا/كشف البنك.
- [ ] **كليك:** المبلغ بالنظام = اللي وصل تطبيق البنك.
- [ ] **المخزون:** جرّب عد 5 إلى 10 أصناف بالرف وقارنها بالنظام (جرد جزئي).
- [ ] **"بيعات مرفوضة":** لازم تكون فاضية. أي بيعة هناك = فلوس بالدرج بلا فاتورة، عالجها فورًا.
- [ ] **التنبيهات الخطيرة:** اقرأها كلها (عجز، إلغاء، إرجاع مشبوه...).
- [ ] **المراجعات:** إرجاعات، ضيافة، تلف، وراجعها وعلّمها.

**ثبت هالأرقام بالأيام الأولى:**
- [ ] الربح الشهري (بصفحة المالية) منطقي مقارنة بحسابك اليدوي؟ لو في صنف "بلا تكلفة" بيطلع تحذير (غالبًا بضاعة افتتاح ناقصة).
- [ ] كشف الشركاء (لو في شركاء) يطلع بنسب معقولة، وما فيه شارة "قديم" أو تحذير تكلفة.

**اجتماع آخر الأسبوع:**
- [ ] كل الفروقات انفسّرت؟
- [ ] أخطاء الكاشيرية الأكثر تكرارًا (إلغاء، إرجاع، باركود غلط)؟ درّبهم عليها.
- [ ] هل النظام وقف أو بطّأ؟ شباك الـAPI سُكّر؟ الأنترنت انقطع؟ شو صار؟

**لا تفتتح إلا إذا:** الفرق بالنقد قريب من الصفر عدة أيام ورا بعض، ولا في بيعة مرفوضة عالقة، والنسخ الاحتياطية شغّالة.

## 5) خطة الطوارئ (اطبعها وعلّقها)

| الحالة | شو تعمل |
|---|---|
| الـAPI وقف أو سكّر شباكه | الكاشير بيكمل أوفلاين تلقائيًا. شغّل الـAPI من جديد ولا تعمل شي للبيعات، بتنبعت لحالها. |
| انقطعت الكهربا | بعد الرجوع: شغّل SQL Server ثم الـAPI. تأكد إن آخر نسخة احتياطية موجودة. |
| النظام كله وقف | دفتر وآلة حاسبة، وسجّل كل بيعة بالدفتر. بعدين أدخل البيعات (أو اتركها بالدفتر وقيّد الفرق). |
| الكاشير قال "حدّث البرنامج" | خذ آخر نسخة من الإدارة، بيعاته المحفوظة ما بتضيع. |
| بيعة مرفوضة بصفحة "بيعات مرفوضة" | افتحها، شوف السبب والأصناف، وعالجها يدويًا (أدخلها بالنظام أو صحّح السبب)، وعلّمها "تمت المعالجة". |
| فرق بالصندوق | سجّل التفسير بصفحة التقفيل، وخلّي الكاشير يوضح. ما تتهم قبل تشوف "بيعات معلّقة" بالتنبيه. |
| فشل النسخ الاحتياطي (تنبيه خطير) | افتح صفحة النسخ، شوف السبب (غالبًا صلاحيات المجلد أو مساحة)، وخذ نسخة يدوية فورًا. |
| بدك ترجّع بيانات | `RESTORE DATABASE` باسم جديد (مش فوق الحقيقية) وافتح عليها، وقارن قبل ما تقرر. |

---

## 6) مؤجَّل بقرارك (لا تنساه قبل ما تكبر)

- **HTTPS:** إلزامي قبل أي وصول من برّا المحل. الشريك من البيت = VPN/نفق (Tailscale أو Cloudflare Tunnel)، **مش** فتح الـAPI عالإنترنت.
- **الطابعة والفاتورة الورقية، درج الكاش، جهاز الفيزا المربوط.**
- **الضريبة** (لو تغيّر وضع المحل).
- **تطبيق الزبائن** على تلفون حقيقي، وتحقق الهوية فيه قبل نشره.
- **CI** تلقائي للاختبارات.
