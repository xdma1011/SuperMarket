# تشغيل المشاريع

كل ملف بيشغّل مشروع لحاله، بدبل كليك. الملفات بتلاقي المشاريع حسب محتواها، مش حسب اسمها أو مسار ثابت، فبتشتغل وين ما نزّلت المشروع.

| الملف | شو بيعمل |
|---|---|
| `0-api-and-web.bat` | التشغيل اليومي: الـAPI ولوحة الإدارة، كل واحد بشباك لحاله. `0-api-and-web.bat cashier` بيفتح الكاشير كمان |
| `1-api.bat` | الـAPI (`dotnet run`) على `http://localhost:5000`، والـSwagger على `/swagger` |
| `2-admin-web.bat` | لوحة الإدارة (`ng serve`)، وبتفتح المتصفح على `http://localhost:4200`. أول مرة بتنزّل الحزم لحالها (`npm ci` بنفس النسخ بالضبط) |
| `3-cashier.bat` | تطبيق الكاشير (ويندوز) |
| `4-customer-app.bat` | تطبيق الزبائن (Flutter) على تلفون أو محاكي. بدّه Flutter SDK |
| `5-tests-backend.bat` | اختبارات الباك إند. بدها قاعدة **تست** (اسمها فيه "test"). بلا Docker، بتحط متغيّر `INTEGRATION_TEST_CONNECTION_STRING` مرة وحدة، وهو مكتوب بأول الملف |
| `6-tests-web.bat` | اختبارات لوحة الإدارة (مرة وحدة، بلا مراقبة) |
| `7-hash-password.bat` | أداة صغيرة: بتكتب كلمة سر وبتطلعلك الـhash لجدول `Users` |
| `_find.bat` | داخلي، الملفات التانية بتستعمله. لا تشغّله لحاله |

- الشباك بيضل مفتوح بالآخر، سواء اشتغل أو فشل، عشان تقرا الرسالة.
- `Ctrl+C` بيوقف الـAPI أو لوحة الإدارة.
- المتطلبات: .NET SDK 10 (للـAPI والكاشير والاختبارات)، وNode.js (للوحة الإدارة). كل ملف بيقلّك إذا إشي ناقص ومن وين تنزّله.
