# دليل تشغيل المحاكاة العشوائية (حبة حبة)

المحاكاة بتعمل محل كامل من الصفر وبتشغّله شهرين بعمليات عشوائية. زبائن بيشتروا، والمدير بيشتري بضاعة ويدفع مصاريف ورواتب، وفي إرجاع وإلغاء وتلف وضيافة وجرد وتقفيل صندوق. بعدين الشهر بيخلص، والشركاء بياخدوا أرباحه وبيسحبوا منها.

جنبها "حَكَم" مستقل بيحسب كل إشي لحاله وبيقارنه بكل تقرير بالنظام. أي رقم مختلف بيطلع قدامك.

> **قاعدتك الحقيقية (`sprmrkt`) ما بتنلمس أبدًا.** المحاكاة بتشتغل على قاعدة تست منفصلة، وبترفض تشتغل على أي قاعدة اسمها ما فيه كلمة `test`.

---

## أول مرة بس (تجهيز، 5 دقايق)

### الخطوة 1: تأكد إنه .NET SDK 10 موجود

افتح **Command Prompt** واكتب:

```
dotnet --version
```

- إذا طلع رقم بيبلّش بـ`10.`، كمّل.
- إذا طلع خطأ، نزّله من https://dotnet.microsoft.com/download (اختار **.NET 10 SDK**)، وبعدين سكّر الـCommand Prompt وافتحه من جديد.

### الخطوة 2: احكي للاختبارات وين قاعدة التست

بنفس الـCommand Prompt، انسخ **سطر واحد بس** من هدول، حسب الـSQL Server عندك.

**إذا الـSQL Server عندك اسمه `MSSQLSERVER_CR7` (نفس اللي بيستعمله البرنامج):**

```
setx INTEGRATION_TEST_CONNECTION_STRING "Server=localhost\MSSQLSERVER_CR7;Database=sprmrkt_integration_tests;Trusted_Connection=True;TrustServerCertificate=True;"
```

**إذا عندك SQL Server عادي بلا اسم:**

```
setx INTEGRATION_TEST_CONNECTION_STRING "Server=localhost;Database=sprmrkt_integration_tests;Trusted_Connection=True;TrustServerCertificate=True;"
```

لازم يطلعلك: `SUCCESS: Specified value was saved.`

- **سكّر الـCommand Prompt.** الإعداد الجديد بيشتغل بس بالشبابيك اللي بتنفتح بعده.
- ما بدك تنشئ قاعدة `sprmrkt_integration_tests` بإيدك. الاختبارات بتنشئها لحالها أول مرة.
- هاد الإعداد بينعمل مرة وحدة، وبيضل محفوظ حتى بعد إعادة تشغيل الجهاز.

### الخطوة 3: نزّل آخر نسخة من المشروع

من مجلد المشروع:

```
git pull origin main
```

## كل مرة بدك تجرّب

### الخطوة 4: شغّل الملف

افتح مجلد المشروع، وادخل على مجلد **`run`**، ودبل كليك على **`8-simulation.bat`**.

### الخطوة 5: جاوب على 3 أسئلة

| السؤال | شو تكتب | ملاحظة |
|---|---|---|
| `How many runs?` | عدد التشغيلات، مثلًا `5` (أو Enter) | كل تشغيلة محل جديد بأصناف وعمليات عشوائية مختلفة |
| `Operations in the first month?` | عدد العمليات، مثلًا `150` (أو Enter) | الشهر الثاني بياخد نصهم. للتجربة الكثيفة اكتب `500` أو `1000` |
| `Replay a specific SEED?` | **اتركه فاضي واكبس Enter** | بتكتب فيه رقم بس لما بدك تعيد تشغيلة فشلت (الخطوة 8) |

### الخطوة 6: استنّى

- أول مرة بيعمل Build للمشروع، وهاد بياخد دقيقة أو اثنتين.
- كل تشغيلة بـ150 عملية بتاخد تقريبًا 30 لـ60 ثانية. وكل تشغيلة بتطبع سطر زي هيك:

```
--- Run 1 of 5 ---
   🎲 البذرة SIM_SEED=815101986 · عمليات المرحلة 1 = 150 · المرحلة 2 = 75
   [OK]
```

### الخطوة 7: اقرأ النتيجة

- **`[OK] All 5 random runs matched every report.`**: كل التقارير طابقت الحَكَم بكل التشغيلات. تمام.
- **`[FAILED] mismatch`** جنب تشغيلة معيّنة: في رقم مختلف. افتح الملف اللي بيقلّك عليه، مثلًا `run\simulation-results\run-3.txt`:
  - **فوق:** رقم البذرة (`SIM_SEED=...`).
  - **بالنص:** كل عملية صارت بالترتيب (بيع، شراء، إرجاع...).
  - **تحت:** الفروقات، كل سطر فيها بيقول شو المتوقع وشو طلع فعليًا، مثلًا:
    `✘ نصيب أحمد من شهر 2026-09: متوقع 55.409 ← فعلي 55.410`

### الخطوة 8: إذا فشلت تشغيلة، ابعتلي الرقم

ابعتلي **رقم البذرة** والسطور اللي فيها `✘`. أنا بعيد نفس التشغيلة بالزبط وبلاقي السبب.

وإذا بدك تشوفها بنفسك، شغّل الملف مرة تانية وجاوب:
- `How many runs?` بـ`1`
- `Replay a specific SEED?` بالرقم

## مشاكل ممكن تواجهها

| الرسالة | السبب والحل |
|---|---|
| `.NET SDK not found` | الخطوة 1 |
| `INTEGRATION_TEST_CONNECTION_STRING is not set` | الخطوة 2 ما انعملت، أو الشباك انفتح قبلها. سكّره وشغّل الملف من جديد |
| `A network-related or instance-specific error` / `Cannot open database` | اسم الـSQL Server بالخطوة 2 غلط، أو خدمة SQL Server طافية. جرّب السطر التاني بالخطوة 2 |
| `رفض تشغيل الاختبارات على القاعدة ...` | الحماية اشتغلت: اسم القاعدة بالخطوة 2 ما فيه `test`. لا تحط `sprmrkt` أبدًا |
| `Build failed` | ابعتلي الرسالة اللي فوقها |

## شو المحاكاة بتغطّي، وشو لأ

**بتغطّي:**
- البيع: كاش، فيزا، مقسوم، بالدين، بالحبة، بالكرتونة، من دفعة، وبالعروض.
- الشراء: بالحبة، بالكرتونة، وبدفعات، ودفعات الموردين، وتسديد ديون الزبائن.
- الإلغاء، والإرجاع، والتلف (والمستبدَل من الشركة)، والضيافة، والجرد الجزئي.
- المصاريف (من الصندوق ومن برّا)، والرواتب والسلف، وتغيير الأسعار، والسحب بسعر التكلفة ("بدفع حقها" و"اخصمها مني").
- تقفيل الصندوق، وكشف أرباح الشهر الماضي، وسحوبات الشركاء من الصندوق ومن جيبك.

**وبتفحص:**
- كل سطر بيع.
- كشف الربح بكل بنوده للشهرين، وإن الشهر الماضي ما بيتغيّر بعد ما نزل كشفه.
- ملخّص المبيعات، والهامش، والمخزون وقيمته بالتكلفة.
- ديون الزبائن والموردين، وكل تقفيل صندوق.
- رصيد كل شريك، والمستحق إلك.

**ما بتغطّي:**
- طلبات تطبيق الزبائن والكوبونات.
- التحويل بين الفروع، وأكتر من فرع.
- البيع بلا نت بسعر نسخة قديمة.

هدول إلهم اختبارات ثابتة منفصلة، بتشتغل مع `5-tests-backend.bat`.
